# リトル・ミュー診断｜GitHub Pages公開版 v7

このフォルダの中身を、GitHubリポジトリ `xiao1213-jpg/LMK2` の一番上へアップロードすると、現在の公開URLを変えずに完成版へ更新できます。

公開URL：<https://xiao1213-jpg.github.io/LMK2/>

## いちばん簡単な更新手順

1. `Little_Mew_GitHub_Publish_v7.zip` をダウンロードして展開します。
2. <https://github.com/xiao1213-jpg/LMK2> を開き、GitHubへログインします。
3. リポジトリ画面右上の **Add file** → **Upload files** を押します。
4. 展開した `Little_Mew_GitHub_Publish` フォルダを開き、その**中身を全部**アップロード欄へドラッグします。
   - `index.html`
   - `assets` フォルダ
   - `share` フォルダ
   - `privacy.html`
   - `.nojekyll`（表示されない場合は省略可）
5. 画面下の **Commit changes** を押します。
6. 1〜3分待って、公開URLを開きます。

ZIPファイルそのものはGitHubへ置かないでください。必ず展開後の中身をアップロードします。

## 初回だけPages設定が必要な場合

公開URLが404になる場合だけ、次を確認します。

1. リポジトリの **Settings** を開く
2. 左側の **Pages** を開く
3. **Source**：`Deploy from a branch`
4. **Branch**：`main`、フォルダ：`/(root)`
5. **Save**

## 公開後の確認

- トップ画面に「性格全体ではなく〜」という診断範囲の説明がある
- 「星図を囲む夜」の要約が「昔の猫が見た星を、今いる仲間ともう一度探す。」になっている
- 診断を最後まで進めると「この猫になった理由」が表示される
- 各結果に「猫になったあなたを、この物語へ案内するのは」と、対応する猫の名前が表示される
- 「ひとつ戻る」と「結果を共有する」が動く
- スマートフォンでも文字やボタンが画面外へはみ出さない

更新が見えない場合は、ページを再読み込みします。それでも古い場合は、ブラウザのプライベートウィンドウで公開URLを開いて確認してください。

## アクセス解析

Google Analytics 4 の測定ID `G-FJ9LS51YKS` は設定済みです。

- 診断開始：`diagnosis_start`
- 診断完了：`diagnosis_complete`
- 結果共有：`share`
- 再診断：`restart`

同じ測定IDを使い続けるため、これまでの集計と公開後の集計は同じプロパティに蓄積されます。ただし、測定タグを設置する前のアクセスは後からさかのぼって記録されません。
